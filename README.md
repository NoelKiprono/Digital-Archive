The Archives repository is a web-based digital archiving project designed to preserve, organize, and showcase local community history and official public records.
It serves two primary purposes:
• The Web Platform: A front-end interface (built with HTML, CSS, and JavaScript) featuring a main homepage, a file browser, a login portal, and layouts tailored for reviewing records.

• The Digital Archive: A curated collection of historical local assets, including town council minutes from 1999, school registers from 1990, land survey records from 1967, and photographs documenting key community events like the opening of the river bridge.
Essentially, it acts as a digital museum and document registry for local community heritage.
